# 三块板卡实现统计与版本

这些统计对应发布包中的归档固件，按 BIT 哈希核对版本。本次未重新综合、实现或上板；RF47 的资源与时钟统计由保存的已布线检查点导出。表中 WNS/TNS 为报告所统计路径的数值。完整报告正文不作改动。

|---|---|---:|---:|---:|---:|---|
| AX7101 | 2026-08-19，trim160s optimized | — | — | — | — | — |
| KU115 | 2026-07-28，packet backpressure fix | 31,700（4.78%） | 40,343（3.04%） | 130.5（6.04%） | 0 | 0.281 / 0 |
| RF47 | 2026-09-21，long PRBS；9 月 22 日固化归档 | 56,064（13.18%） | 55,921（6.57%） | 338（31.30%） | 1,420（33.24%） | 0.033 / 0 |

AX7101 已核对当前固件的版本和哈希，尚未找到与该固件匹配的最终实现统计，因此留空，不填入其他版本的数据。KU115 寄存器数含 4 个锁存器；BRAM 按 36 Kb tile 计，半块对应 18 Kb 配置。

| 板卡 | 主要时钟（MHz） | 依据 |

8 GSPS 是 RF-DAC 采样率，4 Gbaud 是调制符号率，均不等同于 FPGA 并行逻辑时钟。KU115 的 WHS/THS 为 0.004/0 ns，RF47 为 0.010/0 ns。
