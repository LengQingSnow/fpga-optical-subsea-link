# 第三页 CMA-BTB（2026-09-21）

专用启动入口：`start_cma_btb_gui`。先停止其他 GUI 的自动采集。
该入口只读核验当前 RF47 长 PRBS，不切换模式、不重新生成回放、不烧录。
现有 `start_realtime_gui` 仍保留原行为，会准备旧的短参考回放；
当前 262144 符号长 PRBS 测试请使用专用入口。

第三页使用独立 `rf47_cma_btb_dsp.m`：

- 4 Gbaud DP-QPSK，四通道 40 GSa/s，每次单次触发读取 1M 点，读完示波器停止。
- 直流去除、四次方频偏估计、2 MHz 载波陷波、2.8 GHz 低通、2 samples/symbol。
- 2×2 复数、15 抽头、半符号间隔盲 CMA；步长 0.08/0.04/0.02/0.01。
- 连续四次方相位恢复（129 符号窗口）、盲四簇仿射校准。
- 参考只用于前缀映射、同步校验和 BER；不训练 CMA 抽头，不替换接收点。
- 前缀 29900 符号用于收敛及映射，三个独立前缀区间核验同步一致性。
- 当前固定配置失败时尝试其他盲初值/相位支路；不按测试区间 BER 选择参数。
- 每路 35000 个后续、未参与训练/映射拟合的比特用于本次 BER，四路总计 140000。

曲线横轴是采集完成的绝对时间，纵轴是每次窗口 BER（非累计）；零误码显示实际 0。
顶部另外显示累计误码数、总比特数及统计分辨率。零次观测错误不代表真实 BER 严格为零。
同步或参考核验失败时显示 INVALID，不将失败窗口计为零误码。

`rf47_cma_btb_reference` 在启动和每次采集前后只读核验 JTAG：
长 PRBS 标识、模式、周期、种子、延迟/相关设置及 DA 前 1024 符号前缀。
根据固件 PRBS31 递推重建 262144×4 参考，并验证硬件前缀。
JTAG 需要连接 RF47。找不到 RF47 或回放状态改变时不使用旧参考冒充当前参考。
