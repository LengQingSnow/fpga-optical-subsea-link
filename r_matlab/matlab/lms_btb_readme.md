# LMS-BTB 实时页面

这是现有 GUI 的第七页。原有六页的 DSP、共享示波器采集函数和 `start_realtime_gui.m` 保持原样；`main_realtime_eye.m` 仅增加独立页面及其调度分支。修改前备份在 `R_Matlab/backups/lms_btb_page_20260916`。

## 启动

先停止并关闭旧 GUI，确保没有其他程序自动读取示波器。在 MATLAB 2016a 命令窗口运行：

```matlab
cd('r_matlab/matlab');
addpath(pwd);
start_lms_btb_gui;
```

该入口直接选中 LMS-BTB 并开始自动刷新。不重烧 RF47，不切换模式，不重新选择或启动 BER 回放；RF47 必须已处于 QSFP 数据模式并开启 BER 回放，且 JTAG 可连接。原入口也仍可使用，启动后选择 LMS-BTB 标签即可；原入口原有的参考序列准备行为没有改变。

示波器 CH1/2/3/4 对应 X_I/X_Q/Y_I/Y_Q。固定 4 Gbaud、40 GSa/s，每路采集 1M 点。每轮先通过 JTAG 只读获取当前 DA 前回放序列，再发单次触发，等待采集完成后读取同一冻结记录的四路波形，最后再次核对回放序列。采集完成或异常退出时均尝试并核实 STOP；DSP 处理阶段示波器保持暂停。参考改变时清空本页统计，参考无效或采集失败时本次 BER 显示 `--`，不计为零误码。

## DSP 与统计口径

- 使用独立的 4 实数分量、分数间隔归一化 LMS 链路；候选为 571/811/1051 抽头，包含输入白化、独立载波相位恢复和噪声预测。每次采集重新训练，不复用过期信道权重。1051 抽头通过下述校准质量门时提前接受，否则比较全部候选。
- 盲捕获/参考同步仅在前 30k 符号选择；训练截止全局第 49000 个符号。
- 全局 50001–59000 为独立校准段，先按四路总错误数、相同时按残差均方差选择候选。后处理小菜单为 CPR 窗口 3/5，噪声预测阶数 24/80/128，正则参数 0.01/0.03；系数仍只在训练前缀拟合。校准计算最多读取至第 60000 个符号的无标签观测，不接触后面的 BER 测试标签。
- 实时模式先计算已由多组完整扫描验证的 1051 抽头；若校准段零错误且四实分量 MSE 不超过预设 0.01，则接受它，避免重复计算。否则再比较 811/571 抽头。此早停只依据校准质量，不查看最终 BER，也不保证该长度在未来每条记录上都是全局最优。
- 若起始 CMA 重复锁到同一偏振，使用原始混合信号及强偏振残差恢复参考映射，仍须通过三个独立前缀分段和全局移位核对。仅在该恢复分支启用四中心相位/频率跟踪：前 15k 符号学习畸变后的四个中心，16001–30000 选择跟踪增益，后续不读取测试标签。原同步成功路径保持原相位处理，不强制改用新跟踪器。
- 若所有盲四簇仿射校准候选均因簇占据不足而失败，可保留未经该校准的真实 CMA 输出进行参考捕获和相位跟踪；该备用入口不合成星座、不放宽最终同步阈值，也不改变原来校准成功时的候选选择。
- 原恢复仍失败时，强偏振投影额外考虑 -3 至 +3 个符号的延迟，补偿盲 FIR 输出相对原始混合信号的群时延。投影系数仅用前 30k 拟合；再次核对三段同步及全局映射，不能通过则明确显示 BER 不可用。
- 以上路径仍失败时，额外尝试四个原始接收实分量加常数项的低维监督同步器。每个 10k 分段的投影系数由另外 20k 拟合，枚举周期移位，仍要求原同步门限及目标一致性；它不是完全独立的盲验证，三折也用于选移位。最终 FSE 从原始采样重新训练，不把同步投影或理想参考当最终接收符号。该分支保留原盲相位，不强制覆盖为失配的 CMA 模板 PLL；四组随机弱参考负控均被拒绝。
- 单中心同步投影仍失败时，固定加入前后各半个符号，共 3 抽头、12 个实接收特征；不是按结果不断增加长度。原单中心成功路径保持不变。短抽头分支仍须通过原有 0.2 相关门限与三段/全局移位检查，四组随机参考、共同 I/Q 重排及 32 符号块重排负控均被拒绝，后缀标签哨兵测试通过。
- BER 使用全局第 61061–98883 个符号，共 37823 bit/路、151292 bit/窗口。训练比特不计入 BER；保留窗口内所有误码，不按星座质量筛掉坏点。星座显示使用该测试窗口的均匀显示子集，EVM 与 BER 使用完整测试窗口。
- 四路标识为 TX0/XI、TX2/XQ、TX4/YI、TX6/YQ；结果与当前 JTAG 回放参考逐位异或。
- 顶部显示当前窗口 BER、累计 BER、累计错误/比特数、四路累计 BER；下方曲线显示各次采集的非累计窗口 BER，横轴为采集完成时的电脑绝对时间，不是 DSP 处理结束时间。
- 实测零误码数值保持 `0`。对数曲线不能绘制零，故仅将绘图位置置于该窗口的 `1/N` 并用空心圆标注；这不是测得的非零 BER，也不是置信上限。
- 回放为周期序列，此 BER 描述当前回放信号在测试时段的接收结果，不代表任意新业务序列的泛化结果。单窗口零误码不能证明无限长传输 BER 为零。

本算法是逐块刷新，不是持续无间断接收。参考前后两次 JTAG 读取、多长度 LMS 训练及校准选参需要时间；控制栏的刷新间隔不会让运算超出机器实际速度，也不会并发启动第二次采集。点击“停止”后当前正在处理的一轮可能仍需完成；点击本页“清除解调”只清除 LMS-BTB 统计，不影响其他页面。

旧固定 571 版本离线 DSP 约 20.6 秒；新多候选版本用更长更新时间换取更低 BER。有效实时刷新还需加入两次参考读取、采集及绘图时间，不能按控制栏的 2 秒理解为每 2 秒得到一个新结果。处理中保留上一次星座和历史曲线，但本次 BER 显示处理中，不冒充新测量。
