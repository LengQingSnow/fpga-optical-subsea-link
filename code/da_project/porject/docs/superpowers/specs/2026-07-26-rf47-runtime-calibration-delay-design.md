# RF47 运行时方波校准与八路延迟补偿设计

## 目标

在现有且已通过时序的正式链路上增加一套小型校准功能：

```text
QSFP 接收、解帧、缓存 ─┐
                       ├─ 运行时数据源选择 ─ DP-QPSK ─ 八路 RRC/延迟 ─ RFDC
本地方波校准源 ─────────┘
```

正式模式继续使用 KU115 经 QSFP 发送的 64 bit 数据。校准模式由 RF47 本地产生同步方波，八个 DAC 通道在同一次布局布线结果中观测和调节，避免使用两个不同 bitstream 比较通道延迟。

## 不变项

- RF47 工作在 4 Gbaud、2 SPS、8 GSPS。
- RFDC AXIS 时钟保持 500 MHz，每拍 16 个 16 bit 样点。
- QSFP 接收、512 Byte 帧同步、异步 FIFO、DP-QPSK 位映射保持原协议。
- XI/XQ/YI/YQ 对应四组差分输出，偶数通道为 P，奇数通道为 N。
- KU115 工程只读，不做任何修改。
- 当前时序收敛的 bit、xsa、ltx、dcp 和 elf 单独归档，不被新构建覆盖。

## 数据源选择

`rf_mode[0]` 在运行时选择数据源：

| 值 | 数据源 | 行为 |
|---|---|---|
| 0 | QSFP | 使用解帧后的 64 bit 正式数据 |
| 1 | 本地方波 | 64 bit 在全 0 和全 1 之间逐字切换 |

方波源每接受一个 64 bit 字时翻转一次。一个字映射为 16 组相同 DP-QPSK 符号，在连续无反压时每个字持续 4 ns，因此未经 RRC 形状影响的基准翻转频率约为 125 MHz。四个 I/Q 分量使用同一个方波相位，方便示波器同时测量。

校准模式下仍持续读取并丢弃 QSFP FIFO 数据，防止切回正式模式时保留旧数据或 FIFO 溢出。模式只在数据通路暂停时由 JTAG scripts切换。

## 八路延迟码

每个 TX 通道具有一个 7 bit 延迟码：

```text
delay_code[6:5] = 整数样点延迟，0..3
delay_code[4:0] = 分数样点延迟，0..31
```

8 GSPS 下一个样点为 125 ps：

```text
nominal_delay_ps = 125 * integer + 125 * fraction / 32
```

- 名义步进：3.90625 ps。
- 名义范围：0 至 496.09375 ps。
- 延迟只增加，不提前；现场以最慢通道为参考，给较快通道增加延迟。

分数延迟通过 32 相位 RRC 系数实现，不在 500 MHz AXIS 输出后增加大型通用 FIR。每个物理 DAC 通道拥有独立相位，因此 P/N 两端也可独立补偿。奇数通道在各自延迟后的滤波输出上取负。

整数延迟位于 250 MHz、每拍 32 样点的 RRC 输出端。模块保存前一拍样点，并从“前一拍尾部 + 当前拍头部”选择偏移 0..3 样点的连续 32 样点窗口。

## 寄存器表

AXI Lite 基地址保持 `0x80010000`。

| 字索引 | 地址 | 名称 | 位定义 |
|---:|---:|---|---|
| 1 | `0x80010004` | `mtime_start` | 0 停止，1 运行 |
| 6 | `0x80010018` | `rf_mode` | bit0：0=QSFP，1=方波 |
| 7 | `0x8001001C` | `config_done` | 原有总配置完成 |
| 10..17 | `0x80010028`..`0x80010044` | `TX0_DELAY`..`TX7_DELAY` | bit6:0 延迟码 |
| 18 | `0x80010048` | `DELAY_COMMIT` | 每次写 1 翻转提交标志 |

八个延迟寄存器先分别写入，再写 `DELAY_COMMIT=1`。提交时将 56 bit 配置作为一个整体从 100 MHz AXI 域传到 250 MHz 数据域。JTAG scripts在提交前停止数据，等待跨时钟域完成后再恢复，避免半帧使用两套配置。

## 跨时钟域

- `rf_mode` 使用两级同步器进入 250 MHz 域，且scripts在停止状态切换。
- 八路延迟配置由稳定数据总线和提交翻转信号组成。
- AXI 域写提交时锁存 56 bit 影子寄存器并翻转请求位。
- 250 MHz 域同步请求位，检测变化后一次性锁存全部 56 bit。
- 软件在提交前后留出足够等待时间；配置总线在握手期间保持稳定。

## 输出原子性

八路 RRC、整数延迟、gearbox 和 DAC AXIS 仍作为一个原子组推进：

- 只有八路 gearbox 都准备好才接受一个输入字。
- 只有八路 gearbox 都有效且八路 RFDC 都 ready 才推进输出。
- 任一路反压时所有通道保持同一 AXIS 字，禁止通道间数字样点错位。

## 上电默认值

- `rf_mode=0`：正式 QSFP 模式。
- TX0..TX7 延迟码均为 0。
- Vitis 初始化程序先写默认模式和延迟，提交后再置 `config_done` 和 `mtime_start`。

## 验收标准

1. 方波模式下四组 P/N 波形稳定输出，未设置独立延迟时每组 N 等于 P 的逐样点取负。
2. QSFP 模式仍按原有 DP-QPSK 位映射输出。
3. 修改任一路整数延迟只移动该路 1..3 个样点。
4. 修改任一路分数延迟能选择 32 个不同 RRC 相位，码 0 与原始 RRC 系数完全一致。
5. 延迟提交为八路原子更新，运行时无混合配置。
6. 所有 RTL 回归通过。
7. 实现后 DRC 无错误，setup/hold WNS/WHS 非负，无未约束关键数据路径。
8. 生成新的 bit、bin、ltx、xsa、routed dcp、elf 和 JTAG 调节scripts。
