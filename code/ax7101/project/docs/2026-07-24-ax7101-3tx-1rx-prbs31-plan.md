# ax7101 Three-TX One-RX PRBS31 Implementation Plan

> **For agentic workers:** Implement this plan task-by-task with test-first
> development and fresh verification before completion.

**Goal:** Produce a reopenable Vivado project and bitstream for three
1000BASE-T PRBS31 transmitters and one source-aware BER receiver.

**Architecture:** Pure RTL generates and checks raw Ethernet frames on the
ax7101 GMII ports. The original ALINX MDIO modules provide link and speed
status, while dedicated reset synchronizers keep clock domains independent.

**Tech Stack:** Verilog/SystemVerilog, Vivado 2021.2, XSim, Artix-7
XC7A100T-2FGG484I, RTL8211EG GMII.
